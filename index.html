Built while learning

The curriculum is not theoretical. These are products shipped with the same stack the chapters teach — Grok, Vercel, Stripe, Shopify, Xcode. Use them, or use them as proof that a first version can leave the chat window.

  • Billboard One face on a digital billboard. Price starts at a dollar. Worlds, studio, Stripe, Imagine. Grok · Vercel · Stripe · domain
  • Send Reorder Shopify B2B app that drafts the usual order when a company location goes quiet. Shopify · email · boring software
  • Scratchbox Mac menu-bar inbox for screenshots and throwaway files. Nothing stays unless you keep it. Swift · Xcode · local only
  • Meeting Mode A local ritual for calls: focus, a dated note, join from calendar, optional Grok listening. Grok · Mac · no account
  • Roombox Desk software for independent hotels. Working title. The lesson: vibe coding is not only toys. Vercel · TypeScript · in progress
  • Open Mailer One mailbox, many domains. Reply from the address that was written to. Email · DNS · early
